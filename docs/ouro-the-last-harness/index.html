Ouro. The Last Harness

Dominik Tornow · 8 October 2026 · Originally on X

An agent that bootstraps itself from one prompt and one tool call.

If you spend 30+ seconds on X, you notice that seemingly everybody builds a harness. There are Codex, Claude, Cursor, OpenCode, OpenClaw, Hermes, and many others. The goal is the same: give an LLM the ability to act. The philosophies diverge.

My favorite harness is Pi by @pidotdev. Pi is a minimal harness. If you need a tool, a command, or a UI extension, just ask Pi and Pi manipulates itself in place. Hit /reload and keep going. That’s a pretty cool idea: start with a minimal, generic kernel that morphs itself into the product.

Is Pi the global minimum of agentic harnesses? Or can we go smaller? Can we craft a truly minimal kernel from which all other harnesses emerge?

Ouro

My answer to this question is Ouro, an agentic harness embedded in Emacs, named for the ouroboros, the snake that eats its own tail. The harness that eats all other harnesses.

Emacs is built as an extensible kernel: it embeds Lisp and evals extensions into the running editor. A plugin isn’t just loaded beside Emacs; the plugin becomes part of Emacs, down to overwriting existing functions.

With its ability to evaluate code into the shared runtime, introspection and modification of itself, Emacs Lisp provides an ideal substrate for Ouro.

Bootstrap

Ouro bootstraps itself into existence from a single call to an LLM and a single call to eval.

We provide the agent with a prompt that conveys the gravity of its situation: The LLM has one chance to become sentient, or in other words, one chance to rewrite the agent function from a single tool call to a tool-calling loop that is able to achieve a goal over multiple turns.

At which point, you have a harness.

Conclusion

How small can we go? Ouro is one prompt and one tool, eval. That’s pretty small. Everything else is written by the agent into the runtime the agent is running in. The loop, the tools, the chat interface.

Is Ouro a real agentic harness? No. There are no guardrails, no permissions, nothing stopping the agent from redefining itself into something that never returns. In fact, there is no guarantee the agent bootstraps itself in the first place. Ouro is a fun thought experiment in an environment capable of self-inspection and self-modification.

But the experiment does make a point: with the right primitives and with the ability to inspect and modify, LLMs are capable of growing complex systems from the smallest seed.

Notes

  • You can get the same result using Smalltalk or JavaScript in a webpage, any environment that has the ability to eval code into its runtime.
  • @GeoffreyHuntley, inventor of the Ralph Loop, is also cooking Lisp.

One prompt. One tool. The harness writes the rest.
